# Agent Instructions

Team knowledge (known issues, triage rules, conventions) lives in [JuulLabs/kiosk `knowledge/`](https://github.com/JuulLabs/kiosk/tree/main/knowledge).

- If `../kiosk` exists, read `../kiosk/knowledge/` before triaging, fixing or reviewing. Don't clone or pull it yourself; developers opt in by cloning `JuulLabs/kiosk` next to this repo.
- When you confirm something reusable and `../kiosk` exists, add it there following `../kiosk/knowledge/AGENTS.md`.
